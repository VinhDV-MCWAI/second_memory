## What went well

> 🇻🇳 Điều làm tốt.

- **Requirement → design → slices held up a second time.** REQ-002's clarification log uncovered the hidden facts (scale, links only, accent-free search, idempotent import) before any code, so no story changed after the design. QA ran every acceptance scenario and all passed.
- **Measuring before tuning.** The first k6 baseline found that ~28 ms of every request was spent outside the queries; the request profile and the EXPLAIN report turned that into three small, measured changes (persistent connections, stored search vectors, no schema lookup per list) that doubled throughput. Each one was proposed with numbers and taken only after the owner's OK.
- **The contract check paid for itself.** Validating every test response against `openapi.json` caught drift the moment a resource changed, and the FE types stopped being hand-written.
- **Parallel lanes worked.** Up to eight conversations on one branch and one working tree, with path ownership, pathspec commits, file locks and one queue for Docker-backed checks: no lost work and no conflicting test runs. Bugs and follow-ups went to the lane that owns the code instead of being fixed in passing.

> 🇻🇳 Quy trình yêu cầu → thiết kế → lát nhỏ vẫn đúng; đo trước khi tối ưu; kiểm tra hợp đồng OpenAPI bắt lỗi sớm; làm song song nhiều lane không mất việc, không chồng test.

## What went badly

> 🇻🇳 Điều chưa tốt.

- **A change in one lane silently broke another lane's consumer.** P4-02 moved nginx to port 8080 inside the network; the importer's default URL still said port 80 (BUG-01), and nobody searched for consumers of `ml-nginx`. Only QA's exploratory run found it.
- **A config fact was decided at the wrong time.** Persistent connections were chosen with `PHP_SAPI`, which `config:cache` (a CLI command) bakes as `false` for every web request (API-06). It was caught by a perf re-run before the production images built caches, not by a test.
- **The tests checked presence, not order or identity.** Search tests checked that a match is found, not that the best one is first (BUG-04); no test looked at the header, which showed a hard-coded name and a third-party avatar (BUG-03, found by the PO).
- **Bookkeeping is a third of the commits.** Every task ends in a `docs(lab)` commit for the board, backlog and log. It keeps parallel work safe, but the history is noisy to read.
- **The infrastructure work is ahead of its verification.** The Terraform stack is written but not applied (only the owner may run `apply`), so P4-06 … P4-10 wait.

> 🇻🇳 Thay đổi ở lane này làm hỏng chỗ dùng ở lane khác (cổng nginx → importer); một cấu hình được quyết định sai thời điểm (persistent connection và config cache); test chỉ kiểm tra "có kết quả" chứ không kiểm tra thứ tự hay đúng người; một phần ba commit là sổ sách; Terraform đã viết nhưng chưa apply.
