# Lưu trữ: giai đoạn Engineering Lab

Tài liệu của giai đoạn Engineering Lab, trước khi đổi hướng ngày 2026-10-09 ([ADR-0012](../../adr/0012-restore-features-dev-first.md)). Chỉ để tra lịch sử, không cập nhật nữa.

| Thư mục / file | Nội dung |
|---|---|
| `01-analysis.md`, `02-roadmap.md`, `03-backlog.md`, `github-setup.md` | Kế hoạch cũ |
| `refactor-2026-10/` | Kế hoạch và nhật ký đợt refactor trước Engineering Lab. Bảng việc và nhật ký thô của giai đoạn Engineering Lab (`lab/`) đã xóa ngày 2026-10-17; xem lại: `git log -- docs/archive/engineering-lab/lab/` |
| `handbook/` | Sổ tay quy trình kiểu một đội nhiều người: nhận yêu cầu, thiết kế, git, code, QA, phát hành, vận hành, báo cáo |
| `templates/` | Mẫu tài liệu: yêu cầu, thiết kế, ADR, sự cố, báo cáo ngày/tuần, nhìn lại giai đoạn |
| `requirements/` | Hồ sơ yêu cầu: thu gọn hệ thống, Skill Ledger |
| `design/` | Thiết kế: thu gọn hệ thống, Skill Ledger |
| `problems/` | Hồ sơ sự cố: đăng nhập JWT tự viết, test chạy nhầm vào DB dev |
| `reports/` | Báo cáo ngày, tuần, nhìn lại giai đoạn, đo hiệu năng, thử nghiệm tìm kiếm |
| `architecture/as-is.md` | Kiến trúc của bản `v1.0.0` |

**Liên kết hỏng.** Các file này được chuyển vào đây ngày 2026-10-13 mà không sửa nội dung. Liên kết giữa chúng với nhau vẫn đúng. Liên kết từ đây ra `adr/`, `releases/`, `runbooks/`, `plan/` hoặc vào code có thể hỏng: tìm file cùng tên trong `docs/` hoặc trong repo.
