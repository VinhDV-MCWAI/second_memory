# v2.1.0 — Skill Ledger (2026-10-09)

> 🇻🇳 Skill Ledger: kỹ năng, lịch sử cấp độ, mục tiêu học, bằng chứng, tìm kiếm tiếng Việt không dấu, trang công khai và công cụ import từ Obsidian.

The first feature built end to end in the Engineering Lab, through the full lifecycle: a requirement with acceptance criteria, a design, ADRs, vertical slices with tests, a contract check, E2E and load tests, QA sign-off and PO acceptance. The admin core of `v2.0.0` now manages a **Skill Ledger** — skills with an append-only level history, learning goals, evidence (links to PRs, ADRs, incidents, notes) and tags — searchable in one box, published read-only at `/skills`, and fed from Obsidian by a Python importer. The branch also carries the first part of P4: production images, the removal of the unused queue and websocket services, and the first Terraform stack.

> 🇻🇳 Tính năng đầu tiên đi trọn vòng đời trong Engineering Lab. Lõi admin của `v2.0.0` giờ quản lý Skill Ledger, tìm kiếm trong một ô, công khai tại `/skills`, nhập từ Obsidian bằng importer Python. Nhánh này cũng mang phần đầu của P4: image production, bỏ queue/websocket không dùng, stack Terraform đầu tiên.

Requirement: [REQ-002](../requirements/REQ-002-skill-ledger.md). Design: [RFC-002](../design/RFC-002-skill-ledger.md). Decisions: [ADR-0007](../adr/0007-remove-media-api.md) (media API removed), [ADR-0008](../adr/0008-code-first-openapi-contract.md) (code-first OpenAPI + contract tests), [ADR-0009](../adr/0009-postgres-search.md) (PostgreSQL search, two amendments), [ADR-0010](../adr/0010-python-importer-tooling.md) (importer and API token), [ADR-0011](../adr/0011-infrastructure-as-code.md) (infrastructure as code). Acceptance: [v2.1.0-acceptance.md](v2.1.0-acceptance.md). Architecture now: [current.md](../architecture/current.md).

## Highlights

> 🇻🇳 Điểm chính.

| Story (REQ-002) | What shipped |
|---|---|
| US-1 skills and levels | skills with category, slug and visibility; level changes only as new history rows (no edit / delete); current level follows the newest change date |
| US-2 evidence | evidence linking several skills and tags; links validated (`https` only, no `javascript:` / `data:`) |
| US-3 public page | `/skills` and `/skills/{slug}` on the public site, backed by `GET /api/public/skills[/{slug}]`: public items only, a private skill is the same 404 as a missing one, rate-limited per IP, cached 60 s |
| US-4 Obsidian import | `make import vault=<path> [dry=1]`: notes with `publish: true` become evidence, upsert by file path, unpublished notes hidden, admin data never overwritten, a second run changes nothing ([runbook](../runbooks/ledger-import.md)) |
| US-5 search | one box over skills, goals and evidence; Vietnamese typed without diacritics matches, typos fall back to trigram similarity, title matches rank first |
| US-6 goals | learning goals per skill; a level change that reaches the target marks the goal achieved |
| US-7 dashboard | real counts instead of the hard-coded sample numbers |

Around the feature: OpenAPI generated from the code with every test response validated against it and the admin types generated from it (`make openapi`, drift fails `make verify`); a Playwright journey (`make e2e`); k6 load tests (`perf/`); the admin header shows the signed-in admin.

> 🇻🇳 Ngoài tính năng: OpenAPI sinh từ code và được kiểm tra trong mọi test, type FE sinh từ spec; E2E Playwright; k6; header hiển thị đúng người đăng nhập.

## Breaking changes

> 🇻🇳 Thay đổi phá vỡ tương thích.

| Area | Before (v2.0.0) | After (v2.1.0) |
|---|---|---|
| Media API | `/api/admin/media-mgmt/*` (no screen used it) | Gone ([ADR-0007](../adr/0007-remove-media-api.md)). The `media_mgmt` rows and MinIO objects are kept as data |
| Queue and websocket | `ml-queue`, `ml-reverb` containers; Reverb package, `Broadcast::routes`, `jobs` / `job_batches` / `failed_jobs` tables | Gone: nothing queued or broadcast. `QUEUE_CONNECTION=sync`; the `REVERB_*` / `BROADCAST_CONNECTION` variables are unused |
| nginx | listens on 80 / 443 inside the container | `nginx-unprivileged` on 8080 inside; host port unchanged (`NGINX_PORT_OUTSIDE_ENV`, default 81). Anything calling `http://ml-nginx` on the Compose network must use `:8080`; the rate limit now answers `429`, not `503` |
| Containers | some ran as root | none runs as root; images pinned to exact versions (P4-02) |

## Upgrade an existing environment

> 🇻🇳 Nâng cấp một môi trường đang chạy — làm đúng thứ tự.

1. `make backup` (restore point; the drop migrations' `down()` restores structure, not data).
2. Deploy `v2.1.0`. `php artisan migrate` runs, in order: drop the unused `users` and `password_reset_tokens` (`2026_10_08_100001`); create the Skill Ledger tables (`…100002`); search columns and the `unaccent` / `pg_trgm` extensions (`…100003`, the database owner can create both, no superuser); `personal_access_tokens` for the importer (`…100004`); stored search vectors and GiST trigram indexes (`…100005`); drop the queue tables (`2026_10_09_100001`); weighted search vectors (`…100002`).
3. Environment: `make setup` regenerates the env files from the examples. New: `DB_PERSISTENT` (default `true`, one persistent PostgreSQL connection per PHP-FPM worker). Remove the `REVERB_*`, `BROADCAST_CONNECTION` and `NEXT_PUBLIC_REVERB_*` lines. Recreate the stack (`make restart`) so the removed containers go away and nginx moves to 8080.
4. For the importer: mint a token with `php artisan ledger:import-token <owner user name>` (printed once) and store it outside the repository.
5. Smoke check: log in; create a skill with a first level and an evidence; search for it without diacritics; `/skills` shows it when public and answers 404 for a private one; `make e2e` runs the same journey.

**Rollback:** redeploy `v2.0.0` images and restore the backup from step 1. The Skill Ledger tables are new, so rolling back loses only the data entered since the upgrade.

> 🇻🇳 Thứ tự: backup → deploy (một lần `migrate` chạy 7 migration) → cập nhật env (`DB_PERSISTENT`, bỏ biến Reverb) và `make restart` → tạo token cho importer → smoke check. Quay lui = deploy lại `v2.0.0` và restore backup.
