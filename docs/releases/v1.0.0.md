## Highlights of the 2026-10 refactor

> 🇻🇳 Điểm chính của đợt refactor.

- **Security:** Next.js/React CVE fix, secrets removed from git, password hashes no longer returned by list APIs, hardened exception handler, vulnerable frontend dependencies patched (140 advisories → 1 dev-only), blocking production dependency audit in CI.
- **Upgrades:** Laravel 11 → 13, PHP 8.5, PHPUnit 12, Next.js 16.3 with Turbopack and React Compiler, Node 24.
- **Quality gates:** test suite repaired (450 failing → 598 passing), Pint, Larastan level 6, Rector, ESLint + Prettier, Vitest (106 tests, coverage gate), CI on every PR, Dependabot.
- **Architecture:** generic CRUD core, single history mechanism, native enums, split routes, OpenAPI via Scramble with generated FE types, config-driven list pages (5,139 → ~1,060 lines), feature-based FE folders.
- **Operations:** Makefile task runner, pinned MinIO community image, branch auto-cleanup workflow.
