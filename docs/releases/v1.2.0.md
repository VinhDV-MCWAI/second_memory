# v1.2.0 — Content export before the CMS removal (2026-10-07)

> 🇻🇳 Lệnh xuất nội dung CMS ra Markdown, phát hành trước khi xoá CMS ở `v2.0.0`.

A bridge release. It adds one command that exports the CMS content to Markdown, so every environment can save its content **before** upgrading to `v2.0.0`, which drops the content tables ([REQ-001](../requirements/REQ-001-slim-down.md) US-2, [RFC-001](../design/RFC-001-slim-down.md) slice 1). No breaking change.

> 🇻🇳 Bản trung gian: thêm một lệnh xuất nội dung CMS ra Markdown để mọi môi trường lưu lại nội dung **trước khi** nâng cấp lên `v2.0.0` (bản đó xoá các bảng nội dung). Không có thay đổi phá vỡ tương thích.

## Added

> 🇻🇳 Bổ sung.

- `php artisan content:export-markdown [--path=] [--include-deleted]`: one Markdown file per entry with YAML front matter (title, slug, category, created/updated dates), Tiptap JSON converted to Markdown, rows not linked from a layout written to `_uncategorized/` and `_unlinked/`. Idempotent: a second run writes no new or changed files. Runbook: [content-export.md](../runbooks/content-export.md).
- `scripts/metrics.sh [--tests] [--images]`: before/after size metrics (lines of code, tables, routes, tests, image size) as a Markdown table.

## Upgrade

> 🇻🇳 Nâng cấp.

No migration. Deploy as usual, then follow the runbook if this environment will later move to `v2.0.0`.

> 🇻🇳 Không có migration. Deploy bình thường, rồi chạy runbook nếu môi trường này sẽ lên `v2.0.0`.
