# v3.0.0 — Trang tài liệu kinh nghiệm (2026-10-25)

Bỏ Skill Ledger. Kinh nghiệm giờ nằm trong **danh mục và bài viết**, đọc như một trang tài liệu (kiểu Next.js docs, Laravel docs) nhưng xếp theo kiểu diễn đàn. Bản này gộp hai yêu cầu: trang tài liệu kinh nghiệm ([REQ-005](../requirements/REQ-005-trang-tai-lieu-kinh-nghiem.md), thiết kế [ADR-0022](../adr/0022-trang-tai-lieu-kinh-nghiem.md), 8 bước KB-01…KB-08) và trang chủ tóm tắt + trang đọc 4 cột ([REQ-006](../requirements/REQ-006-trang-chu-va-trang-doc.md), thiết kế [ADR-0024](../adr/0024-trang-doc-chuyen-trang-khong-tai-lai.md), 6 bước READ-01…READ-06; chủ dự án yêu cầu 2026-10-25, trước khi gắn tag). Khoảng 70 commit từ `v2.3.0` (`git log --oneline v2.3.0..v3.0.0`).

Số chính tăng lên 3 vì bản này **xóa hẳn một tính năng và dữ liệu của nó** (xem "Thay đổi phá vỡ tương thích").

## Nâng cấp một môi trường đang chạy

| # | Lệnh | Vì sao |
|---|---|---|
| 1 | `make backup` | **Bắt buộc**: migration xóa bảng Skill Ledger |
| 2 | Lấy code bản `v3.0.0` | |
| 3 | `make up`, rồi `docker restart ml-nginx` | Trang public và trang quản trị có trang mới. nginx đổi giới hạn request (file dev của Vite có giới hạn riêng), `nginx -s reload` không nhận đổi này nên phải khởi động lại |
| 4 | `make migrate` | 8 migration: xóa Skill Ledger; nhóm → danh mục, đính kèm, bài nhiều danh mục, bài cha; file nhúng trong bài; quyền ↑ ↓ và xem trước; lượt xem và cột tìm kiếm; khóa nhập Obsidian; lượt xem danh mục, ☆ danh mục và mục đang đọc |
| 5 | `make seed` (chỉ dev, nếu muốn) | Dữ liệu mẫu mới: nhóm Quy trình (10 danh mục × 2 bài), nhóm Kỹ năng (4 danh mục có đính kèm), sách "Laravel thực chiến" 3 cấp |
| 6 | Tạo lại token nhập Obsidian (nếu dùng `make import`) | Token cũ hết dùng |

Không có biến môi trường mới. Quay lui: khôi phục bản sao lưu ở bước 1 rồi dùng code bản `v2.3.0`. `migrate:rollback` dựng lại được các bảng Skill Ledger nhưng **không có dữ liệu**.
