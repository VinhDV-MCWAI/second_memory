# v3.0.0 — Trang tài liệu kinh nghiệm (2026-10-25)

Bỏ Skill Ledger. Kinh nghiệm giờ nằm trong **danh mục và bài viết**, đọc như một trang tài liệu (kiểu Next.js docs, Laravel docs) nhưng xếp theo kiểu diễn đàn. Yêu cầu: [REQ-005](../requirements/REQ-005-trang-tai-lieu-kinh-nghiem.md). Thiết kế: [ADR-0022](../adr/0022-trang-tai-lieu-kinh-nghiem.md). Làm theo 8 bước trên bảng việc, khoảng 30 commit từ `v2.3.0` (`git log --oneline v2.3.0..v3.0.0`).

Số chính tăng lên 3 vì bản này **xóa hẳn một tính năng và dữ liệu của nó** (xem "Thay đổi phá vỡ tương thích").

## Thay đổi phá vỡ tương thích

| Thay đổi | Ảnh hưởng | Xử lý |
|---|---|---|
| **Bỏ Skill Ledger**: 9 bảng (kỹ năng, cấp độ, mục tiêu học, bằng chứng, nhãn và các bảng nối), 19 quyền, API `admin/{skill,skill-level,learning-goal,evidence,tag}/*`, `public/skills/*`, 4 màn hình quản trị | **Dữ liệu Skill Ledger bị xóa** khi chạy migration. Kỹ năng, bằng chứng đã lưu trong ☆ 🔖 của người dùng mất theo | Sao lưu trước (bước 1 bên dưới). Chép nội dung muốn giữ sang danh mục và bài viết |
| Trang public: `/skills`, `/skills/{slug}`, `/guides/{danh mục}`, `/guides/{danh mục}/{bài}` | Link cũ | Tự chuyển hướng 301 về `/`, `/categories/{slug}`, `/articles/{bài}`. Kỹ năng cũ không còn danh mục cùng tên thì ra trang "không tìm thấy" |
| Bài viết: một bài nhiều danh mục, đường dẫn bài **không trùng trên cả trang** (trước: không trùng trong một danh mục) | API `admin/article/*` nhận `category_ids` thay cho một danh mục | Trang quản trị và trang public đã sửa cùng bản |
| Công cụ nhập Obsidian | Token cũ (khóa `evidence:import`) không dùng được nữa; biến `LEDGER_NOTE_BASE_URL` bị bỏ | Tạo token mới: `docker exec ml-php php artisan ledger:import-token <tên đăng nhập>` |
| API `user/saved/*` | Chỉ nhận `article`; `user/saved/list` chỉ còn `kind`, `key`, `title`, `article_slug`, `saved_at` | Chỉ trang public dùng, đã sửa cùng bản |

## Nâng cấp một môi trường đang chạy

| # | Lệnh | Vì sao |
|---|---|---|
| 1 | `make backup` | **Bắt buộc**: migration xóa bảng Skill Ledger |
| 2 | Lấy code bản `v3.0.0` | |
| 3 | `make up` | Trang public và trang quản trị có trang mới |
| 4 | `make migrate` | 7 migration: xóa Skill Ledger; nhóm → danh mục, đính kèm, bài nhiều danh mục, bài cha; file nhúng trong bài; quyền ↑ ↓ và xem trước; lượt xem và cột tìm kiếm; khóa nhập Obsidian |
| 5 | `make seed` (chỉ dev, nếu muốn) | Dữ liệu mẫu mới: nhóm Quy trình (10 danh mục × 2 bài), nhóm Kỹ năng (4 danh mục có đính kèm), sách "Laravel thực chiến" 3 cấp |
| 6 | Tạo lại token nhập Obsidian (nếu dùng `make import`) | Token cũ hết dùng |

Không có biến môi trường mới. Quay lui: khôi phục bản sao lưu ở bước 1 rồi dùng code bản `v2.3.0`. `migrate:rollback` dựng lại được các bảng Skill Ledger nhưng **không có dữ liệu**.
