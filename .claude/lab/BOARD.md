# Parallel work board

> 🇻🇳 Bảng công việc song song. Nhiều conversation cùng làm trên **một branch, một thư mục**; mỗi lane sở hữu thư mục riêng nên không giẫm chân nhau.

Several conversations work at the same time on the same branch and working tree. Each **lane** owns its paths; a lane runs **one task at a time** (one conversation per lane). Start a conversation with `/lane` (any free lane) or `/lane <lane>`. Rules: [.claude/rules/parallel-lanes.md](../rules/parallel-lanes.md).

> 🇻🇳 Mở conversation, gõ `/lane` (tự chọn lane rảnh) hoặc `/lane <tên lane>`. Mỗi lane chỉ một task `doing` tại một thời điểm.

**Never edit the Status column by hand** — use `scripts/lane.sh claim | done | block | release` (they lock the board). Add rows with `scripts/lane.sh add`.

Status: `todo` → `doing since …` → `done …` | `blocked: …`. Depends: IDs that must be `done` first (`–` = none). The plan stays in [03-backlog.md](../../docs/plan/03-backlog.md); `done` mirrors the status there when the ID exists.

> 🇻🇳 Không sửa cột Status bằng tay — dùng `scripts/lane.sh`. Kế hoạch gốc vẫn ở `03-backlog.md`; khi `done`, script cập nhật luôn dòng tương ứng trong backlog.
