# infra — Terraform environments

> 🇻🇳 Hạ tầng bằng Terraform cho `staging` và `prod-like`. Dev vẫn chạy bằng Compose (`docker/`), không đổi.

Decision and layout: [ADR-0011](../docs/adr/0011-infrastructure-as-code.md). Dev stays on Compose (`make up`); Terraform describes the `staging` and `prod-like` environments, which run the production images on the same Docker engine with their own names (`sm-<env>-<service>`), network, volumes and the label `sm.env=<env>`.

> 🇻🇳 Quyết định và bố cục ở ADR-0011. Môi trường Terraform chạy image production trên cùng Docker engine với tên, network, volume riêng và nhãn `sm.env=<env>`.

## Use

```bash
make tf-images                 # build sm-api / sm-nextjs-fe / sm-nextjs-docs:<short sha> from committed code
make tf-plan                   # env=prod-like by default; tag=<image tag> to run other images
make tf-apply                  # shows the plan and asks; waits until every container is healthy
make tf-destroy                # removes the containers, network and volumes (data is lost)
infra/tf.sh prod-like output   # any other Terraform command
```

Open `http://localhost:9443` (prod-like). Nothing is installed on the host: Terraform runs in the tools image (`infra/Dockerfile`, Terraform 1.16.3) with the Docker socket mounted, as the host user. `make tf-*` go through `scripts/lane.sh run`, so they never overlap another lane's test run.

> 🇻🇳 Không cài gì trên máy: Terraform chạy trong image công cụ, mount Docker socket, chạy bằng user của máy. Các target `make tf-*` đi qua `lane.sh run` nên không chạy chồng lên test của lane khác.

## What is where

| Path | Content |
|---|---|
| `Dockerfile` | Tools image (Terraform; SOPS + age join in P4-09) |
| `build-images.sh` | Builds the production images from `git archive <ref>`: another lane's uncommitted files never reach an image |
| `tf.sh` | Runs Terraform for one environment in the tools image; state files get mode 600 |
| `modules/stack/` | Docker provider: network, volumes, postgres, redis, migrate (one-shot), php-fpm, nextjs, docs, proxy |
| `live/<env>/stack/` | Root module of an environment: `terraform.tfvars` (no secrets), committed `.terraform.lock.hcl`, local state (git-ignored) |

- **Configs are shared with Compose:** `docker/nginx/*.conf`, `docker/postgres/pg_hba.conf` and `docker/redis/redis.conf` are read with `file()` and uploaded into the containers; the proxy's upstream names `ml-*` are swapped for `sm-<env>-*`.
- **Migrations** run in a one-shot `sm-<env>-migrate` container before php-fpm starts; it reruns when the API image or its environment changes.
- **Secrets** (DB / Redis passwords, `APP_KEY`) are generated by the `random` provider and live in the state until SOPS + age (P4-09). The state is a secret: never commit or back it up.
- **Lost state:** `docker rm -f $(docker ps -aq --filter label=sm.env=prod-like)`, the same for `docker network` / `docker volume`, then `make tf-apply`.

> 🇻🇳 Cấu hình nginx / PostgreSQL / Redis dùng chung với Compose (đọc bằng `file()`, đổi tên upstream `ml-*` thành `sm-<env>-*`). Migration chạy trong container một lần trước php-fpm. Secret do provider `random` sinh và nằm trong state cho tới P4-09 — state là secret, không commit, không backup. Mất state: xoá theo nhãn rồi apply lại.

## Limits until later P4 tasks

- **P4-03:** the docs app has no production build yet (`docs_enabled = false`, `/docs` answers 502); the admin app bakes `NEXT_PUBLIC_API_URL` at build time; the API image is ~1.6 GB and builds no Laravel caches.
- **P4-06:** no MinIO in these environments yet. **P4-07:** only `prod-like` has a root. **P4-08:** HTTP on 9443, no TLS, no `*.sm.localhost` names, so the admin login is not set up for this origin.

> 🇻🇳 Giới hạn: docs chưa có bản build production (P4-03), FE admin còn nhúng URL API lúc build; chưa có MinIO (P4-06); mới có root `prod-like` (P4-07); chưa có TLS và tên miền `*.sm.localhost`, nên đăng nhập admin chưa cấu hình cho origin này (P4-08).
